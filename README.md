# Battle Box Studio

FFVII-style blue battle box math game — testing ground for the kids game.

- Nova is the only player-controlled character. Sage and Pip auto-fight.
- Menu appears only on Nova's turn. Attack = math question, 4 answers + type-your-own.
- Downed fighters fall flat until healed / revived (Sage auto-revives, Phoenix Down in Items).
- Win: victory song, everybody dances. Lose: enemy dances, Start Over.
- Jobs: Tank / Striker / Mage / Healer.
- 3D Character Lab under Trigger Random Encounter — upload .glb hero / enemy files.
- Blue battle box sits inside the battlefield, flush with the game screen.

Live: deploy via Cloudflare Pages from this repo (index.html).
